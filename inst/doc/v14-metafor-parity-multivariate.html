Multivariate and Multilevel Meta-Analysis

František Bartoš

25nd of October 2026

This vignette is a starting point for fitting multivariate and multilevel meta-analytic models with the RoBMA R package (Bartoš & Maier, 2020). We walk through four datasets from the metadat package (Viechtbauer et al., 2026), showing the brma.mv() call alongside its metafor::rma.mv() counterpart (Viechtbauer, 2010). The examples move from a simple three-level model to known sampling covariance matrices, temporal correlation structures, and two simultaneous random structures.

The first two examples rely on default prior distributions and the last two examples rely on unit-information-scaled prior distributions; see the Prior Distributions vignette for more details. For generic summaries, plots, and diagnostics that also apply to brma.mv() objects, see the Bayesian Meta-Analysis vignette.

Three-Level Model

The dat.konstantopoulos2011 dataset from the metadat package contains 56 standardized mean differences from studies of modified school calendars and student achievement. Positive values indicate higher achievement for students on modified calendars, and schools are clustered within districts. Effect sizes yi and sampling variances vi are already provided.

data("dat.konstantopoulos2011", package = "metadat")
dat_konstantopoulos <- dat.konstantopoulos2011
head(dat_konstantopoulos)
#> 
#>   district school study year     yi    vi 
#> 1       11      1     1 1976 -0.180 0.118 
#> 2       11      2     2 1976 -0.220 0.118 
#> 3       11      3     3 1976  0.230 0.144 
#> 4       11      4     4 1976 -0.300 0.144 
#> 5       12      1     5 1989  0.130 0.014 
#> 6       12      2     6 1989 -0.260 0.014

The metafor package fit uses a compound-symmetric random effect for schools within districts. We set struct = "CS" explicitly so that the fitted random structure is visible in the call. The shorter brma(..., cluster = district) syntax for this special case is shown in the Multilevel Meta-Analysis vignette.

fit1_metafor <- metafor::rma.mv(
  yi, vi,
  random = ~ school | district,
  struct = "CS",
  data = dat_konstantopoulos
)
fit1_metafor

The matching brma.mv() call passes the sampling variances through V and uses the cs() random-effect formula tag. The cs(school | district) term estimates one shared heterogeneity standard deviation and one within-district correlation for the school effects.

fit1_brma <- brma.mv(
  yi = yi, V = vi, measure = "SMD",
  random = ~ cs(school | district),
  data = dat_konstantopoulos, seed = 1,
  chains = 4, adapt = 2000, burnin = 5000, sample = 10000,
  parallel = TRUE, autofit = FALSE
)

summary() reports the pooled effect and the random-effect parameters monitored by the fitted Bayesian model. Here tau is the shared marginal heterogeneity SD corresponding to the metafor package variance component, and district: rho is the compound-symmetric correlation.

summary(fit1_brma, include_mcmc_diagnostics = FALSE)
#> 
#> Bayesian Multivariate Random-Effects Model (k = 56)
#> 
#> Estimates
#>      Mean    SD 0.025   0.5 0.975
#> mu  0.181 0.088 0.013 0.179 0.363
#> tau 0.321 0.054 0.237 0.314 0.449
#> rho 0.631 0.137 0.335 0.645 0.856

Known Sampling Covariance

The dat.assink2016 dataset from the metadat package contains standardized mean differences from 17 studies on recidivism and mental health among delinquent juveniles. Most studies contributed multiple estimates for different delinquent behaviors, so the example needs both a working sampling covariance matrix and random effect specification. The working sampling covariance matrix and the random-effects formula address different sources of dependence. The working sampling covariance matrix encodes sampling-error dependence that is treated as known, while the random-effects formula estimates residual heterogeneity across the levels named in random.

The metafor::vcalc() call constructs a working sampling covariance matrix from the effect-size variances, study labels, delinquency type, and effect-size identifiers.

data("dat.assink2016", package = "metadat")
dat_assink <- dat.assink2016
V_assink   <- metafor::vcalc(
  vi, cluster = study, type = deltype, obs = esid,
  rho = c(0.7, 0.5), data = dat_assink
)
head(dat_assink)
#> 
#>   study esid id      yi     vi pubstatus year deltype 
#> 1     1    1  1  0.9066 0.0740         1  4.5 general 
#> 2     1    2  2  0.4295 0.0398         1  4.5 general 
#> 3     1    3  3  0.2679 0.0481         1  4.5 general 
#> 4     1    4  4  0.2078 0.0239         1  4.5 general 
#> 5     1    5  5  0.0526 0.0331         1  4.5 general 
#> 6     1    6  6 -0.0507 0.0886         1  4.5 general

The metafor::rma.mv function then specifies the V matrix and nested random intercept for studies and effect sizes within studies as the input.

fit2_metafor <- metafor::rma.mv(
  yi, V_assink,
  random = ~ 1 | study / esid,
  data = dat_assink
)

The brma.mv() call mirrors the same inputs: V is the known sampling covariance matrix and random describes the multilevel specification.

fit2_brma <- brma.mv(
  yi = yi, V = V_assink, measure = "SMD",
  random = ~ 1 | study / esid,
  data = dat_assink, seed = 2,
  chains = 4, adapt = 2000, burnin = 5000, sample = 10000
)

The summary function here deviates from the metafor input because it summarizes parameters with directly specified prior distributions. Here, it is the total between-study heterogeneity tau and variance allocation of tau^2 into the individual levels.

summary(fit2_brma, include_mcmc_diagnostics = FALSE)

Heterogeneous AR(1) Structure

The dat.ishak2007 dataset from the metadat package contains results from 46 studies of deep-brain stimulation for Parkinson’s disease. Negative mean differences indicate improvements in UPDRS motor-function scores, and repeated follow-up measurements within studies motivate a temporal correlation model. The data are first reshaped to long format, and metafor::vcalc() uses a working autocorrelation of 0.97 for the sampling errors.

data("dat.ishak2007", package = "metadat")
dat_ishak <- dat.ishak2007
dat_ishak <- reshape(
  dat_ishak,
  direction = "long",
  idvar     = "study",
  v.names   = c("yi", "vi"),
  varying   = list(c(2, 4, 6, 8), c(3, 5, 7, 9))
)
dat_ishak <- dat_ishak[order(dat_ishak$study, dat_ishak$time), ]
dat_ishak <- dat_ishak[!is.na(dat_ishak$yi), ]
rownames(dat_ishak) <- NULL
dat_ishak$time_factor <- factor(dat_ishak$time)
V_ishak <- metafor::vcalc(
  vi, cluster = study, time1 = time,
  phi = 0.97, data = dat_ishak
)
head(dat_ishak)
#> 
#>               study mdur mbase time    yi   vi time_factor 
#> 1    Alegret (2001) 16.1  53.6    1 -33.4 14.3           1

The metafor package uses struct = "HAR" for a heterogeneous AR(1) true-effect structure over time within studies. The fixed effects estimate one mean difference at each time point, with the intercept suppressed.

fit3_metafor <- metafor::rma.mv(
  yi, V_ishak,
  mods = ~ 0 + time_factor,
  random = ~ time | study,
  struct = "HAR",
  data = dat_ishak
)

The brma.mv() call uses the har() random-effects formula tag. To obtain separate parameters for each time_factor level, we specify the independent factor contrast via prior_mods argument (only suppressing the intercept via -1 would fix the default’s level coefficient 0). Because this outcome is a generic continuous outcome and sample sizes are not reported in the source table, we use one of the primary-study sample sizes to estimate the unit-information scale. The Alegret (2001) row reports a 3-month sampling variance of 14.3, and the primary study reports 15 patients. We compute the corresponding unit-information standard deviation with estimate_unit_information_sd() and use it directly in the prior distribution specification.

ishak_unit_information_sd <- estimate_unit_information_sd(sei = sqrt(14.3), ni = 15)

fit3_brma <- brma.mv(
  yi = yi, V = V_ishak, measure = "GEN",
  mods = ~ 0 + time_factor,
  random = ~ har(time | study),
  prior_effect              = NULL,
  prior_mods                = prior_factor(
    distribution = "normal",
    parameters   = list(mean = 0, sd = ishak_unit_information_sd),
    contrast     = "independent"
  ),
  prior_unit_information_sd = ishak_unit_information_sd,
  data = dat_ishak, seed = 3,
  chains = 4, adapt = 2000, burnin = 5000, sample = 10000,
  parallel = TRUE, autofit = FALSE
)
summary(fit3_brma, include_mcmc_diagnostics = FALSE)

The HAR structure lets the heterogeneity differ by time point while estimating one autocorrelation across neighboring time points. This separates the temporal structure of the true effects from the working temporal dependence already encoded in V_ishak.

Study and Treatment Random Effects

The dat.begg1989 dataset from the metadat package contains 20 estimates of two-year disease-free survival rates for acute nonlymphocytic leukemia. The studies compare allogeneic bone-marrow transplantation (BMT) and conventional chemotherapy (CMO), with both controlled two-arm studies and uncontrolled one-arm studies. The example uses the reported survival rates and their sampling variances directly on the raw rate scale. Because the source table reports survival rates and standard errors but not sample sizes, we recover effective sample sizes and use them to scale the prior distributions.

data("dat.begg1989", package = "metadat")
dat_begg <- dat.begg1989
dat_begg$trt <- relevel(factor(dat_begg$trt), ref = "CMO")
dat_begg$ni  <- as.numeric(round(with(dat_begg, yi * (1 - yi) / sei^2)))
head(dat_begg)

The metafor package model combines a study intercept with a treatment-specific random effect. The study intercept captures heterogeneity in baseline survival. The treatment-specific component allows the BMT and CMO estimates to vary within studies, with the treatment-level correlation fixed at zero by rho = 0.

fit4_metafor <- metafor::rma.mv(
  yi, vi,
  mods = ~ trt,
  random = list(
    ~ 1 | study,
    ~ trt | study
  ),
  struct = "CS",
  rho    = 0,
  data   = dat_begg,
  method = "ML"
)

The brma.mv() sets names for the two random structures explicitly. The prior_random() call specifies the study and treatment blocks directly because it fixes the treatment-level correlation at zero.

begg_unit_information_sd <- estimate_unit_information_sd(sei = dat_begg$sei, ni = dat_begg$ni)

sd_prior <- prior(
  distribution = "normal",
  parameters = list(mean = 0, sd = begg_unit_information_sd),
  truncation = list(lower = 0, upper = Inf)
)
cor_zero <- prior(
  distribution = "spike",
  parameters = list(location = 0)
)
cs_zero <- random_covariance(
  cor       = cor_zero,
  cor_scale = "cor"
)

fit4_brma <- brma.mv(
  yi = yi, V = vi, ni = ni, measure = "GEN",
  mods = ~ trt,
  random = list(
    study     = ~ 1 | study,
    treatment = ~ cs(trt | study)
  ),
  prior_heterogeneity = prior_random(
    study     = random_block(sd = sd_prior),
    treatment = random_block(
      sd         = sd_prior,
      covariance = cs_zero
    )
  ),
  prior_unit_information_sd = begg_unit_information_sd,
  data = dat_begg, seed = 4,
  chains = 4, adapt = 2000, burnin = 5000, sample = 10000
)
summary(fit4_brma, include_mcmc_diagnostics = FALSE)
